A chess engine in under 4 KB of Python 3 (stdlib only), entered in make.fun's [tiny-chess-01](https://make.fun/bounty/tiny-chess-01) bounty. `main.py` is generated by the kit's `makefun compress` from a readable source.

- 10x12 mailbox board, flipped so the side to move is always upper case
- full legal moves: castling, en passant, promotion (to queen)
- negamax alpha-beta, quiescence, transposition table, check extension,
  null move, late-move reductions, futility, killer + history ordering
- tapered piece-square eval from formulas, repetition draws
- iterative deepening to a fixed node budget, never a clock: same position,
  same move

License: MIT.

## Run it

```sh
MAKEFUN_ENV_URL=<house server URL> python3 main.py
```
